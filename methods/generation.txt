ProRiboGen generation module — Methods

======================================================================
1. Protein representation (VESM-3B)
======================================================================

ProRiboGen does not encode amino-acid sequences online. For each protein p
with sequence of length L_p, we run a frozen pretrained VESM-3B encoder
(ESM2-3B backbone with VESM-3B weights; hidden size D_p = 2560) once and
store per-residue embeddings. Special tokens are stripped so that the stored
tensor is aligned to amino acids:

    E^{(p)} = (e_1^{(p)}, ..., e_{L_p}^{(p)})  in  R^{L_p x D_p}.

Sequences longer than the encoder context are processed in overlapping
windows of 1022 residues; overlapping positions are averaged. These
embeddings are frozen and reused for all subsequent training and sampling.

Batching. Within a minibatch, residue embeddings are padded to the batch-
maximum length. A binary mask marks valid residues:

    m^{(p)} in {0,1}^{L_p},    m_j^{(p)} = 1 if residue j is real, else 0.

Layer-wise projection. At every Transformer layer, the frozen embeddings
are mapped into the RNA model width H = 512 by a learned affine map
(independent per layer):

    h_j^{(p)} = W_p e_j^{(p)} + b_p,
    W_p in R^{D_p x H},   b_p in R^H,

yielding token-level protein features

    H^{(p)} = (h_1^{(p)}, ..., h_{L_p}^{(p)})  in  R^{L_p x H}.

Global protein vector. Adaptive LayerNorm uses a mask-weighted mean of the
projected residues:

    c^{(p)} = ( sum_{j=1}^{L_p} m_j^{(p)} h_j^{(p)} )
            / ( sum_{j=1}^{L_p} m_j^{(p)} )     in R^H.

Because the map is affine, this is equivalent to pooling in D_p and then
projecting. We keep both representations: c^{(p)} as a global condition and
H^{(p)} as residue-level keys/values. Padding positions are excluded from
pooling and from protein–RNA cross-attention via m^{(p)}.


======================================================================
2. RNA tokenization and sequence formatting
======================================================================

RNA is tokenized with a custom 1-mer vocabulary of size |V| = 11:

    {<unk>, <pad>, <mask>, <cls>, <eos>, <bos>, A, C, G, U, N}.

Sequences are prefixed with <cls>. During training an <eos> token is
appended to enable variable-length generation. The maximum generated RNA
content length is L_max = 80 nt.


======================================================================
3. Architecture overview
======================================================================

The RNA diffusion backbone is a 6-layer bidirectional Transformer encoder
based on EsmForMaskedLM.

    Component                   Configuration
    -------------------------   ------------------------------------------
    Hidden dimension H          512
    Number of layers            6
    Attention heads             16
    Head dimension              32
    FFN hidden dimension        2048
    Position encoding           Rotary Position Embedding (RoPE)
    Attention type              Bidirectional (non-causal)
    FFN activation              GLU with SiLU gating


======================================================================
4. Protein conditioning
======================================================================

Each layer injects protein information in two complementary ways, using the
representations defined above.

(i) Adaptive LayerNorm (AdaLN).
Before self-attention, RNA hidden states H are LayerNormed and then
modulated by the global vector c = c^{(p)}:

    LN~(H) = LN(H) odot (1 + gamma(c)) + beta(c),
    (gamma, beta) = Linear(c),

where odot is elementwise scaling. The same AdaLN form is applied again
before the FFN, with a separate Linear map.

(ii) Gated protein–RNA cross-attention.
RNA tokens are queries and projected protein tokens H^{(p)} are keys/values
(padding masked by m^{(p)}):

    Attn(H, H^{(p)}) = softmax( Q(H) K(H^{(p)})^T / sqrt(d_h) ) V(H^{(p)}).

A learned sigmoid gate controls residual injection:

    g = sigma(W_g LN(H)),
    H <- H + g odot Out(Attn(H, H^{(p)})).

AdaLN supplies a protein-wide context; cross-attention aligns RNA positions
to residue-level features.


======================================================================
5. Forward corruption process
======================================================================

Training uses an absorbing-state masked diffusion process. Given a clean RNA
sequence x_0 = (x_0^1, ..., x_0^L), we sample a continuous noise level

    t ~ U(eps, 1),    t = eps + (1 - eps) u,    u ~ U(0,1),    eps = 10^{-3}.

Each valid (non-special) token is independently replaced by <mask> with
probability t:

    x_t^i = <mask>   with probability t,
            x_0^i    otherwise.

Every example is constrained to contain at least one masked token. The
training target y is defined only on masked sites:

    y^i = x_0^i     if x_t^i = <mask>,
          -100      otherwise,

so unmasked positions are excluded from the loss.


======================================================================
6. Training objective
======================================================================

Let f_theta(x_t | P) denote token logits under protein condition P
(i.e. E^{(p)} and m^{(p)}). The diffusion reconstruction loss is a
length-summed cross-entropy on masked tokens, reweighted by 1/t:

    L_diff = E_{x_0,t,x_t}
             [ (1/t) * sum_{i: y^i != -100}  CE( f_theta(x_t | P)_i , x_0^i ) ].

To encourage protein specificity we add a positive–negative ranking term.
For the same corrupted RNA x_t we evaluate masked-token CE under the true
protein P+ and a randomly sampled negative protein P- (preferentially
another protein in the minibatch):

    CE+ = CE( f_theta(x_t | P+) , y ),
    CE- = CE( f_theta(x_t | P-) , y ),
    L_rank = E[ ReLU( m + CE+ - CE- ) ],    m = 0.2.

The total loss is

    L = L_diff + alpha * L_rank,    alpha = 0.2.


======================================================================
7. Reverse sampling (generation)
======================================================================

Inference starts from a fully masked content canvas of length L_max with a
leading <cls>, conditioned on the target protein embeddings, and iteratively
unmasks over T = 50 steps.

Let t_k decrease linearly from 1 to eps over k = 0, ..., T-1, and write
s = t_{k+1}. At each step the model predicts distributions over still-masked
positions. Candidate tokens are sampled with temperature tau = 1.0 and
nucleus filtering (top-p = 0.90), restricted to valid RNA content tokens
(and <eos> in variable-length mode).

We use MaskGIT-style confidence decoding (maskgit_plus). For each masked
site, confidence is the probability of the sampled token. The number of
positions transferred from <mask> to discrete tokens at step k is

    n_k = floor( M_k * (1 - s / t_k) ),

where M_k is the current number of masked tokens (all remaining masks are
filled on the last step). The top-n_k sites are chosen by Gumbel-perturbed
confidences

    score = conf / tau_alg + Gumbel(0,1),    tau_alg = 0.8,

and filled with their sampled tokens; the rest stay masked. Decoding stops
when no masks remain. In variable-length mode, generation terminates at the
first <eos>, yielding sequences of length <= L_max.


======================================================================
8. Optimization and data
======================================================================

Training used the motif-balanced ProRiboGen RNA–RBP pairs with
distributed AdamW (lr = 1.4e-4, betas = (0.9, 0.95), weight decay = 0.01),
bfloat16 mixed precision, gradient clipping at 1.0, and an effective batch
size of 512. Models were trained for up to 20 epochs; the released 6-layer
generator checkpoint was used for the main generation experiments unless
otherwise noted.
